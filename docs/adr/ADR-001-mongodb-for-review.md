# ADR-001: review-service DB로 MongoDB 선택

**날짜**: 2026-05-27
**상태**: 승인됨

## 배경

리뷰 도메인은 카테고리마다 평가 항목이 다르다.
- 필터 커피: 원산지, 로스팅, 추출 방식, 산미·바디·향
- 위스키: 증류소, 숙성 연도, 캐스크, 피트·달콤함
- 와인: 생산 지역, 빈티지, 품종, 타닌·산도

신규 카테고리 추가 시 스키마 변경 없이 확장되어야 한다.

## 결정

review-service와 feed-service의 DB로 **MongoDB**를 선택한다.

## 근거

- Document 모델이 카테고리별 가변 필드를 자연스럽게 수용
- 신규 카테고리 추가 시 스키마 마이그레이션 불필요
- 리뷰 조회는 대부분 장소 단위·사용자 단위 → 복잡한 JOIN 불필요
- 이미지 URL 배열, 평가 항목 Map 등 중첩 구조 표현에 적합

## 결과

- 카테고리별 평가 항목은 `Map<String, Object>` 필드로 저장
- 카테고리 스키마 정의는 category-service(PostgreSQL)에서 관리
- 리뷰 작성 시 category-service에서 스키마 조회 후 유효성 검증
